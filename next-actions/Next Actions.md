Frontend query system for the whole vault — each note in this folder is a single-purpose live view, nothing to maintain by hand.

**Tasks**
- [[All Open Tasks]] — everything not done, grouped by project
- [[Today]], [[This Week]], [[Due or Overdue]] — deadline triage at different zoom levels
- [[Recently Completed]] — last 7 days, for a weekly review
- [[No Context]] — tasks missing a `#task-category/...` tag, a data-hygiene check
- By context: [[Calls]], [[Errands]], [[Computer]], [[Someday]]

**Waiting on someone else**
- [[Waiting For]] — flat list, each task linked back to its project
- [[Stuck Projects]] — same data, grouped by project instead

**Projects**
- [[All Projects]] — grouped by category tag (`project/...`)
- [[Archived Projects]] — done, moved out of the way (`005 archive/`)
